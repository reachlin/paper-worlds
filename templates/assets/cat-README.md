# Cat frames — the default player's poses

Extracted from [papertrails](https://github.com/xikhar/papertrails) — `public/textures/art/animals.png`,
the `cat_calico` poses (sit, walk_a, walk_b). (c) 2026 Shikhar, MIT — same author and licence as the
engine. The sit frame stands in for the standing pose (the sheet has no stand). A world may replace
these with its own hero art (assets/hero*.png) or a generated painted cat (references/hero-art.md).
